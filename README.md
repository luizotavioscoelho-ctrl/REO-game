# REO-game
🎮 REO GAMES

REO GAMES é um portal de jogos e experimentos interativos desenvolvido pela REO Labs. O projeto reúne pequenas experiências que podem ser executadas diretamente no navegador, com suporte para dispositivos móveis.

🚀 Sobre o projeto

A proposta do REO GAMES é oferecer jogos simples, criativos e interativos, além de experiências que permitem explorar conceitos de física, gravidade, magnetismo e mistura de cores.

O site é desenvolvido em HTML, CSS e JavaScript, com foco em acessibilidade, praticidade e compatibilidade com celulares e computadores.

🕹️ Jogos e experimentos

- Clique Cósmico: acumule energia e avance em sua pontuação.
- Desvie!: controle um veículo e evite obstáculos.
- Laboratório de Cores: experimente combinações de cores.
- Mini Sandbox: interaja com elementos como areia, água, pedra e fogo.
- Ímã Maluco: explore forças magnéticas e o movimento de partículas.
- Gravidade Livre: crie planetas e partículas para experimentar forças gravitacionais.

✨ Recursos

- Interface adaptada para dispositivos móveis.
- Controles por toque e mouse.
- Experimentos interativos em tempo real.
- Diferentes temas visuais.
- Simulações de física e movimento de partículas.
- Jogos executados diretamente no navegador.

🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Canvas API

▶️ Como jogar

1. Acesse o site do REO GAMES.
2. Escolha um jogo ou experimento.
3. Toque em JOGAR.
4. Use os controles disponíveis para interagir.

Não é necessário instalar um aplicativo para jogar pelo navegador.
